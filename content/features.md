## Fitur

### Backend API

- **Transaksi**: buat transaksi, ambil list, statistik, logs, cancel, retry.
- **Callback ke client**: kirim hasil transaksi ke `cb_url`.
- **Auth dashboard**: register/login, profile, dan 2FA (TOTP).
- **IDV gateway**: initialize/login/check session/logout, produk (sync/update), home/session utilities.
- **Account**: API key, regenerate, whitelist.
- **Web push**: subscribe/unsubscribe/test notification.
- **Home request**: start/stop/status/request home data (jika di-enable).

### Dashboard

- Login & manajemen akun (termasuk 2FA).
- Monitoring transaksi + statistik + logs.
- Pengaturan koneksi cookie (H2H sementara disembunyikan).
